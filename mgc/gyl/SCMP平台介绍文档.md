# SCMP 产供销一体化供应链决策平台 — 介绍文档

> 适用于项目进度汇报 / 系统演示 / 新成员上手

## 平台定位

SCMP（Supply Chain Management Platform）是「认养一头牛」乳业的产供销一体化供应链决策平台，覆盖**牧场奶源 → 生产制造 → 库存仓配 → 渠道经销**全链路管理。

前后端分离架构，49 个业务页面，17 个后端服务模块，48+ 张数据表。

## 二、各模块功能介绍

### 2.1 工作台

#### 流程协同与待办中心
跨模块统一审批入口。集中展示来自订单审批、MDM 变更请求、调拨单审核的待办事项，支持审批/驳回操作。自动生成催办提醒，支持按超时级别（P0-P3）分级显示。

#### 经营分析与管理驾驶舱
面向管理层的 BI 看板。核心指标包括：订单匹配率、履约成功率、库存周转率、区域销售对比、7 日趋势图。按日/周/月维度聚合，支持风险预警汇总。

---

### 2.2 业务运营（核心）

#### 智能订购中心
订单管理与智能匹配。创建销售订单后，系统按多因子评分算法（库存权重 32%、距离 22%、新鲜度 20%、成本 14%、优先级 12%）自动匹配最优发货仓库。

#### 订单闭环中心
订单全生命周期追踪。状态流：草稿 → 审核通过 → 已分配 → 已出库 → 运输中 → 已签收。包含履约轨迹跟踪、异常检测（缺货/临期/超安全库存）、补货建议生成。

#### 库存与仓配运营中心
批次级库存台账与调拨管理。核心功能：
- **库存台账**：按仓库×SKU×批次号粒度管理，追踪可用量/锁定量/在途量、剩余保质天数
- **调拨单**：仓库间调拨，全流程 DRAFT → 待审核 → 已批准 → 已出库 → 已完成
- **库存预警**：低库存/超库存/临期/断货，四级严重度（低/中/高/严重）
- **交易流水**：入库/出库/调出/调入/冻结/解冻/调整/报损 八类变更记录

#### 渠道与经销商经营中心
渠道合作伙伴全生命周期管理：
- 经销商档案（信用等级、区域、默认仓库）
- 合同管理（合作中→暂停→终止）
- 价格政策审批流（草稿→待审→通过→驳回）
- 风险监控（低销/高频/越区/合同到期），跟进记录追踪

#### 渠道需求计划
多版本渠道需求预测。按计划→版本→数据行的三层模型，支持按渠道×SKU×周维度填报需求量。版本状态流：草稿 → 提交中 → 待确认 → 已确认。含产品锁定规则（促销期锁定需求量不可编辑）。

#### 渠道需求提报 🆕
**近期新增模块。**将已确认的需求计划分配到具体仓库执行。核心能力：
- 自动仓库匹配：按省份优先级（本省→邻省→其他）排序，结合可用库存
- 可配置仓库数量（N 个）和分配比例（手动调节百分比）
- 分配明细表格内联编辑，库存不足自动红色预警
- 确认后生成发货指引（Excel 导出）
- 下发生效：自动创建调拨单 + 锁定对应仓库库存

#### 牧场与奶源运营中心
牧场端数据看板。展示日产奶量、质量检测、出货记录、温控数据。

---

### 2.3 主数据管理（MDM，仅超级管理员可见）

#### 商品管理
- **SKU 管理**：商品编码目录，7 段式标准编码规则 `SKU-{品类}-{工艺}-{规格}-{包装}-{属性}-{流水号}`
- **标准商品 SPU**：产品聚合层，关联品类
- **品类管理**：树形产品分类（如 乳业→液态奶→UHT 纯牛奶）

#### 仓库 / 工厂管理
仓库目录（常温/冷藏/冷冻，自有/第三方）、工厂目录

#### 渠道管理
- **渠道管理**：树形渠道体系（一级→二级→三级，如 线上→电商→天猫）
- **经销商管理**：经销商目录，关联渠道与区域

#### 组织与日历
- **组织机构**：公司组织架构树
- **业务日历**：节假日/工作日标记，按月份展示

#### 关系配置（4 项关联表）
- 仓库-SKU 关系（某仓库存放哪些 SKU）
- SKU-经销商关系（经销商有权销售哪些 SKU）
- 组织-经销商关系（哪个部门管理哪些经销商）
- 产品-SKU 转换关系（SPU 到 SKU 的映射）

#### 主数据治理平台
数据质量保障引擎。6 种校验规则（唯一性、格式、必填、引用完整性、时间范围、跨对象一致性），变更请求工作流（草稿→待审核→已生效/已驳回），质量问题和冲突跟踪。

---

### 2.4 权限与系统

#### 组织权限
- **部门管理**：中心/部门/小组三级架构
- **用户管理**：账号生命周期，关联角色+岗位+部门
- **角色管理**：角色定义 + 页面权限分配
- **岗位管理**：岗位目录，关联部门
- **权限管理**：页面权限树查看
- **权限精细化控制**：字段级可见/可编辑权限配置

#### 系统配置与运维
- **系统配置中心**：算法权重、预警阈值、流程参数等可配置项，支持版本历史
- **系统健康运维视图**：服务状态/CPU/内存/数据量一览
- **接口与任务监控**：API 调用量/错误率/延迟实时监控

#### 安全与审计
- **登录日志与安全中心**：登录成功/失败/异常统计，四级风险等级
- **操作日志**：所有 CRUD 操作留痕，含变更前后快照
- **审计日志**：企业级审计查询与 CSV 导出

#### 平台工具
- **字典中心**：系统枚举值管理（数据范围类型、导入导出状态等）
- **导入任务**：Excel 批量导入，含错误行 CSV 下载
- **导出任务**：数据导出任务管理与文件下载

## 三、权限模型

### RBAC 核心架构

```
用户 (Account) ──→ 角色 (Role) ──→ 页面权限 (Page)
     │
     └──→ 岗位 (Post) ──→ 部门 (Department)
```

- **超级管理员**：绕过所有权限校验，通过环境变量 `SUPER_ADMIN_LOGIN_IDS` 配置
- **业务角色**：业务运营经理、需求计划专员、仓配运营主管等
- **权限粒度**：页面级，支持按模块路径精确控制
- **数据范围**：角色支持 `ALL` / `DEPT` / `DEPT_AND_CHILD` / `SELF` 四级

### 认证流程

```
登录 → JWT 签发(12h) → 前端 localStorage 存储
     → 每次请求 Bearer Token → 后端解析 JWT → 构建 RBAC 上下文
     → 路由守卫检查 permissionPath
```

## 四、技术架构

| 层 | 技术栈 |
|----|--------|
| 前端框架 | Vue 3 + TypeScript |
| 构建 | Vite 7 |
| UI 组件 | Element Plus |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 |
| 图表 | ECharts 6 |
| 后端 | Express 5 |
| 认证 | JWT (jsonwebtoken) |
| 数据存储 | JSON 文件（localDb），MySQL 可选 |
| 安全 | Helmet + Rate Limit (400 req/min) |
| 文件处理 | Multer + XLSX |

### 数据层特点

- **原子持久化**：读写经由 `localDb.js` 统一管理，写操作使用原子 rename
- **单文件存储**：`server/local-data/db.json` 包含全部数据
- **缓存策略**：内存缓存 + 文件修改时间检测
- **数据隔离**：`system`（权限）、`master`（主数据）、`biz`（业务）、`platform`（平台）四个命名空间

## 五、近期进展（2026-05）

### 第一期：新鲜度规则引擎
- 新增 fresh 规则配置中心（6 条默认规则：临期/短保/常规 × 常温+冷链）
- 日期时间规则（截单时间/提前期/非工作日/配送窗口）
- 分配算法集成：效期过滤 + FEFO 排序 + 距离约束
- SKU 增加 temperature_zone 字段

### 第二期：档期规则 + 计划更新
- 档期定义 + 分配规则（大促/节日/季节性可切换仓库权重）
- 滚动更新：基于已确认版本自动生成下一期
- 修订工作流：申请→审批→生成修订版

### 第三期：低温需求提报
- 独立低温提报模块：仅冷藏仓 + 运输时效 24h/500km
- 强制 FEFO + 到货效期门槛 + 紧急补货通道
- 最小批量按 SKU 配置

### 第四期：日分仓调拨
- 周→日拆解算法（跳过非工作日 + 提前期 + 截单时间）
- 仓库主管按日查看/调整调拨量
- 确认后自动合并生成调拨单并锁定库存

### 数据层优化（全期贯穿）
- `nextId()` O(n)→O(1)（WeakMap 缓存）
- 库存台账 Map 索引 + 编号计数器
- 预警改为写后触发 + 版本对比单次遍历
